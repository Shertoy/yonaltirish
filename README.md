# Yo'naltiruvchi bot

Eski @Koreystili40kunda_bot tokeni uchun. Yagona vazifasi: kimdir yozsa,
yangi bot manzilini aytadi.

## Render'da sozlash

1. Yangi "Background Worker" turida xizmat yarating (Web Service emas -
   bu botda veb-sahifa yo'q, faqat orqa fonda ishlaydi)
2. GitHub'dagi shu papkani ulang
3. Environment o'zgaruvchilar:
   - `BOT_TOKEN` - ESKI token (@Koreystili40kunda_bot)
   - `YANGI_BOT` - `@Zabongo_Bot` (xohlasa boshqa nom qo'yish uchun)
4. Start Command: `python bot.py` (Procfile o'zi buni beradi)

Baza kerak emas, domen kerak emas, veb-server kerak emas.
